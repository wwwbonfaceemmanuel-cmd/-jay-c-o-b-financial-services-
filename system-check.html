Test an administrator account

Signs in through Supabase Auth, reads the account's role from profiles, and — if the role is a staff role — performs one small write to prove the policies accept it. Nothing is changed on the website.

If something is red

  1. Table missing → paste the whole of supabase/schema.sql into Supabase → SQL Editor → New query → Run.
  2. Sign-in fails → create the user in Supabase → Authentication → Users, then run select public.promote_staff('your@email');
  3. Write refused → the account is not staff yet: run promote_staff and sign in again.
  4. Documents empty → open the admin portal, save Website Settings once, and reload this page.
  5. Nothing at all → the URL and key are missing: set them in Railway or in assets/js/config.js.

Full instructions: DEPLOY.md in the repository.
